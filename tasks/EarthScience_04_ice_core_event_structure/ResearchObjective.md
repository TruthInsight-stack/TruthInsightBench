# Long-Record Sulfate Event Structure in an Ice Core

- Task ID: `EarthScience_04_ice_core_event_structure`
- T0: `2019-01-01`

## Research objective

Study the ordered sulfate, density, depth, age, and event-signal measurements for reproducible event structure and long-record relationships. Compare alternative background, peak, and time-window definitions, and report where apparent event classes or chronological relationships are stable, fragile, or unresolved.
