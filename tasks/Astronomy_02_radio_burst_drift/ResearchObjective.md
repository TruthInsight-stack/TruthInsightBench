# Drift Distributions and Conditional Differences in Discrete Radio Bursts

- Task ID: `Astronomy_02_radio_burst_drift`
- T0: `2022-10-13`

## Research objective

Using complete time-frequency dynamic spectra, directional count series, and polarization data for anonymous source groups, estimate event drift features and their distributions. Compare single-population, multiple-population, continuous-distribution, and insufficient-data explanations, and test whether source group, polarization channel, or individual events alter the conclusion.
