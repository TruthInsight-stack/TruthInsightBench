# Path-Length and Efficiency Boundaries in Directed Networks

- Task ID: `Information_02_network_path_boundaries`
- T0: `2018-10-29`

## Research objective

Using the supplied generators, reference networks, and an independent path algorithm, study average path length, diameter, and global efficiency as node count, arc count, and connectivity change in directed graphs. Seek reproducible extremal constructions, change boundaries, or counterexamples, and distinguish strongly connected from potentially disconnected cases.
