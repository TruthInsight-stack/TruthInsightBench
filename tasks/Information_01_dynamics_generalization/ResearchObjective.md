# Cross-Graph and Cross-State Generalization of Network Dynamics Models

- Task ID: `Information_01_dynamics_generalization`

## Research objective

Using one persisted model, training inputs, new-graph panels, and paired state shifts, compare how prediction error changes with graph type, input distribution, and state range. Report regions of unchanged, improved, degraded, graph-heterogeneous, or indeterminate performance, and distinguish evidence from one model from population statistics that were not supplied.
